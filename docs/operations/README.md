# Operación y validación

Guías para tareas concretas. La instalación y el arranque local se mantienen en el [README principal](../../README.md); no hace falta ejecutar estos procedimientos para explorar la interfaz.

| Tarea | Guía |
|---|---|
| Comprobar un productor con una demo aprobada aislada | [Validación del AI Coach](ai-coach-validation.md) |
| Entender el despliegue gradual del pipeline | [Pipeline v2](pipeline-v2-rollout.md) |
| Publicar, recuperar o revertir exports | [Publicación y rollback](canonical-publication-rollback.md) |
| Validar fixtures y semántica del parser | [Corpus golden](golden-corpus.md) |
| Localizar scripts operativos y sus parámetros | [Scripts del servicio Go](../../backend/go-service/scripts/README.md) |

Consultar una guía no autoriza reprocesar el corpus, adquirir demos, entrenar ni publicar. La validación aislada y la publicación tienen destinos y gates diferentes; aplica el [plan canónico](../AI_COACH_IMPLEMENTATION_PLAN.md) y [AGENTS.md](../../AGENTS.md) al alcance de la tarea.
