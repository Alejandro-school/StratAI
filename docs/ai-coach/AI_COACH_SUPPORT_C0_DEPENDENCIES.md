Complementa el [protocolo C0](AI_COACH_SUPPORT_PRE_ENTRY_PROTOCOL.md), el [piloto](AI_COACH_INITIAL_PILOT_DESIGN.md) y el [informe de cobertura](../archive/ai-coach/AI_COACH_SUPPORT_PREPARATION_JOINT_COVERAGE_PHASE_2026-09-16.md).

## Qué permite la evidencia actual

C0 acredita cortes prospectivos respecto de una ventana posterior, población, exclusiones y hechos iniciales propios/aliados. La unión exacta de sus nueve contextos permite medir coincidencia factual. No acredita que T0 sea anterior al inicio físico de un movimiento ni a una entrada, ni que una alternativa sea viable o superior. S2 exige preparar apoyo antes de entrar; S3 exige comparar conectar con la función y el coste de mantener otra posición. Una posición separada o una ventana sin cambio no es un error ni una intención observada.

La matriz siguiente identifica una **fuente positiva requerida**, no una fuente nueva encontrada. Las pruebas independientes son criterios futuros, no validaciones ya realizadas. Sólo se reabre el componente para el que llegue material suficiente; no se exige resolver todos los componentes para verificar una pieza factual independiente.

## Punto exacto de continuación

La consolidación no aporta una nueva fuente positiva que elimine estas dependencias. No hay una décima unión factual justificada por sumar campos o trasladar NAV/rayos. Tampoco acredita un defecto funcional por la mera ausencia de datos. El paso mínimo previo a otra implementación S2–S3 es **recibir material nuevo y verificable para uno de los requisitos anteriores**, con ruta local y alcance de uso explícitos.

Para el requisito temporal principal S2, ese material debe incluir frontera orientada previamente definida, vínculo de geometría/transformaciones con la demo y prueba temporal suficiente para acreditar anterioridad. Un paquete exacto de assets sería útil para abrir su comprobación independiente, pero por sí solo no resuelve frontera, contacto, alternativas ni S2–S3. Se acepta verificar un componente independiente si es el que dispone de prueba nueva; su alcance se fija a partir del material, no para completar un número de fases.

Sin ese material, la siguiente intervención dependiente queda bloqueada. No se solicita descargarlo, adquirirlo ni contactar a terceros. El prompt de continuación debe comprobar primero esta condición y detenerse si sigue incumplida, sin repetir inventarios negativos, smokes de la misma ausencia ni ampliar el trabajo. Producto, interfaz temporal, catálogo, decisiones, elegibilidad, corpus, temporales anteriores y CURRENT permanecen protegidos.
